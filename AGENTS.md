# AGENTS.md — laravel-aura

Laravel 13 auth scaffolding package (Breeze clone). 5 stacks: blade, livewire, react, vue, api. Tailwind CSS 4. PHP 8.3+.

## Quick commands

```bash
composer install
vendor/bin/testbench workbench:install   # generate workbench/ (embedded Laravel app)
composer test          # Pest (unit + arch tests)
composer format        # Pint (laravel preset)
composer analyse       # Larastan level 5 on src/
vendor/bin/pint --test # Pint dry-run (used in CI, stricter than `composer format`)
vendor/bin/testbench serve   # serve workbench/ app
```

## CI order (`.github/workflows/tests.yml`)

1. `vendor/bin/pint --test` (format check, must pass with no diffs)
2. `composer analyse` (phpstan level 5)
3. `composer test` (pest)

Run all three locally before pushing. `pint --test` is read-only; `composer format` applies fixes.

## Architecture

- **Entry point**: `src/AuraServiceProvider.php` (spatie/laravel-package-tools)
- **Commands**: `aura:install {stack}` and `aura:publish-stubs`
- **Install flow**: `InstallCommand` → delegates to trait per stack (`src/Console/Concerns/Installs*Stack.php`)
- **Stubs**: `stubs/{common,blade,livewire,react,vue,api,inertia-common}/`. If app has `stubs/aura/{group}/`, those override package stubs.
- **Tests**: Pest + Orchestra Testbench. `tests/TestCase.php` extends Testbench's TestCase. Arch tests enforce no debug statements in `src/`.

## Key quirks

- `workbench/` is generated by testbench — run `workbench:install` before `testbench serve`. Only `vendor/`, `composer.lock`, and `.env` inside it are gitignored; generated code may be committed if desired.
- `phpstan.neon` scans only `src/`, not `tests/`. Level 5.
- Tests auto-bind `TestCase` via `tests/Pest.php`.
- `composer test` includes arch tests — `dd`, `dump`, `ray`, `var_dump` in `src/` will fail.
- Stubs path resolution: `InstallCommand::stubsPath()` checks `base_path("stubs/aura/{$group}")` first, falls back to package `stubs/`.
- `--force` flag on `aura:install` skips all confirmation prompts and overwrites files.

## Working conventions

- Code style: Pint `laravel` preset (`pint.json`).
- `.editorconfig`: 4-space indent for PHP, 2-space for JSON/YAML.
- Namespace: `Vendor\Aura\` (PSR-4 in `composer.json`).
- Do not commit `composer.lock` or `build/` artifacts.
